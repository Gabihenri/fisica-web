Compatibilidade

Arduino Uno/Nano usam numeração digital D0–D13. Outras placas podem ter mapeamento diferente; confira a pinagem da placa antes da montagem.

HC-SR04 → Arduino Uno

VCC → 5V

GND → GND

TRIG → D9

ECHO → D10

⚠️ Para sensores de 3,3 V e placas como ESP32, a ligação elétrica pode exigir adaptação de nível. Não conecte sinais incompatíveis sem conferir a especificação do módulo.

Código Python
Exemplo para receber medições pela porta serial e gravar os dados para análise.
import serial
import csv

PORTA = "COM3"  # altere para a porta do seu computador
BAUDRATE = 115200

with serial.Serial(PORTA, BAUDRATE, timeout=2) as ser:
    with open("dados_fisica_web.csv", "w", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["tempo_s", "medida"])
        for _ in range(100):
            linha = ser.readline().decode(errors="ignore").strip()
            if linha:
                writer.writerow(linha.split(","))

print("Dados salvos em dados_fisica_web.csv")
