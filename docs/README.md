# Documentação — Física Web

Este diretório concentra a documentação oficial do projeto Física Web.

## Estrutura documental

- `architecture/` — arquitetura da aplicação, componentes, fluxo de dados e decisões técnicas.
- `database/` — modelo Supabase/PostgreSQL, segurança RLS, migrações e dicionário de dados.
- `accessibility/` — requisitos e decisões de acessibilidade multimodal: audiodescrição, Libras/VLibras, contraste, ampliação, voz e interação assistiva.
- `research/` — continuidade científica da pesquisa, metodologia, protocolos experimentais e indicadores de investigação.
- `experiments/` — especificação dos experimentos de queda livre, pêndulo simples e plano inclinado.
- `reports/` — especificação de gráficos, relatórios experimentais, audiodescrição e parecer pedagógico.
- `deployment/` — Render, variáveis de ambiente, deploy e operação.
- `roadmap/` — requisitos consolidados, funcionalidades implementadas, pendências e evolução planejada.

## Princípio de organização

O código executável permanece separado da documentação. Nenhuma credencial, chave do Supabase, segredo do Render ou dado pessoal de estudante deve ser versionado neste repositório.

## Fluxo oficial

Requisito → documentação → implementação controlada → deploy → validação → atualização documental.
