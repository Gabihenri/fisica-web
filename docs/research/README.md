# Pesquisa

O Física Web é uma evolução tecnológica da temática de pesquisa sobre a ação da gravidade no ensino inclusivo de Física.

## Objetivo tecnológico-científico

Construir um laboratório web multimodal que permita executar, registrar, analisar e interpretar experimentos de gravidade, oferecendo diferentes formas de acesso aos mesmos fenômenos e resultados.

## Princípios

- experimentação real e registro de dados;
- comparação entre métodos experimentais;
- análise estatística e erro experimental;
- acessibilidade multimodal;
- explicação pedagógica dos resultados;
- rastreabilidade das medições;
- dados pseudonimizados para pesquisa;
- possibilidade futura de análises longitudinais por turma, série, escola, experimento e recursos funcionais utilizados.

Qualquer uso formal dos dados com participantes deve observar consentimento, ética em pesquisa e proteção de dados aplicáveis.
