# Experimentos

## Queda livre

Entradas principais: altura e tempo. Estimativa de gravidade: `g = 2h/t²`, no modelo ideal adotado.

## Pêndulo simples

Entradas principais: comprimento e período. Estimativa: `g = 4π²L/T²`, para pequenas oscilações dentro das hipóteses do modelo.

## Plano inclinado

Entradas principais: ângulo, distância e tempo. A aceleração é estimada cinematicamente e relacionada à componente gravitacional paralela ao plano.

## Requisitos comuns

Cada experimento deve preservar dados brutos, número da medição, valor calculado de g, condições experimentais e observações. O resultado agregado deve conter média, dispersão, erro percentual, mínimo, máximo e classificação interpretável pedagogicamente.
